# Глоссарий

- **Agent I/O Gateway** — персональная коммуникационная и защитная граница
  агента.
- **Protocol Adapter** — тонкий преобразователь конкретного внешнего протокола.
- **Control Plane** — идентичности, политики, реестры, бюджеты и аудит.
- **Execution Plane** — процессы, агенты, sandbox и артефакты.
- **Authority Plane** — применение привилегированных операций и credentials.
- **Secret Guardian** — анализирует обоснованность секретной операции по
  метаданным.
- **Credential Broker** — детерминированно использует credential, не раскрывая
  его моделям.
- **Capability** — ограниченное право выполнить именованное действие над
  определённым ресурсом.
- **Delegation chain** — проверяемая цепочка передачи ограниченных полномочий.
- **Task Contract** — структурированное описание подзадачи, границ и результата.
- **Evidence Bundle** — доказательства выполнения и качества результата.
- **Staged Action** — подготовленное, но ещё не применённое изменение.
- **Action Receipt** — проверяемая квитанция о фактически выполненном действии.
- **Provenance** — происхождение данных, команды, решения или артефакта.
- **Taint** — метка недоверенного происхождения, наследуемая производными
  данными.
- **DLP** — исходящий контроль утечки секретов и чувствительных данных.
- **Skill** — переносимый пакет инструкций, scripts и ресурсов для класса задач.
- **Constitutional Core** — минимальный набор правил, не изменяемых обычным
  агентом или skill.
- **ACP** — Agent Client Protocol для взаимодействия клиента или редактора с
  агентом разработки.
- **MHS** — Model Hardware Standard, принятый слой взаимодействия с физическим
  оборудованием через аппаратные drivers и safety constraints.
- **Local Agent Host** — локальный системный runtime для параллельного запуска и
  изоляции нескольких процессов, команд и agent instances.
- **Agent Factory** — контролируемый сервис создания временных субагентов по
  `AgentSpawnRequest`.
- **Pattern Compiler** — собирает agent instance из процессного паттерна, роли,
  skills, модели, контекста, capabilities и бюджета.
- **Effort Unit** — относительная единица затрат, калиброванная относительно
  референсной сильной модели; не обязана иметь денежный эквивалент.
- **Dormant Specialist** — проверенный профиль субагента, который можно
  активировать для новой задачи только с новой identity, контекстом и правами.
- **Function Pack** — версионированный комплект patterns, специалистов, skills,
  policies, evals и adapters для автоматизации устойчивой функции.
- **Capability Card** — машиночитаемая карточка назначения, прав, запретов,
  входов, выходов, риска и evidence компонента.
- **Transaction Mandate** — ограниченное разрешение на конкретный класс
  транзакций без раскрытия платёжных или иных credentials.
- **Process Pattern** — версионированная операционная модель длительной работы:
  lifecycle, роли, артефакты, checkpoints и критерии завершения.
- **Role Profile** — контракт ответственности, входов, выходов, контекста и
  максимальных capabilities конкретной роли.
- **Agent Instance** — временный исполняемый экземпляр полной агентной сборки.
- **Agent Build ID** — digest существенных версий и настроек Agent Instance.
- **Identity Fabric** — слой идентичностей людей, организаций, процессов,
  workloads, агентов, сервисов и устройств.
- **Trust Profile** — ограничения работы с внешним principal независимо от
  совместимости его протокола.
- **Policy Simulator** — механизм replay и оценки новой policy до активации.
- **Agent SLO** — показатели качества, безопасности, затрат и надёжности
  агентной конфигурации и процесса.
- **Shadow Mode** — выполнение candidate-конфигурации без production side
  effects для сравнения с утверждённой сборкой.
- **Delegation Value Gate** — проверка ожидаемой пользы и ограничений перед
  созданием новой ветви субагентов.
